The joke the reviewer laughs at. Your program writes one text (a one-line joke about working beside AI coding agents), an AI judge compares the texts two at a time, and the 20 best win rates share $35.

## What it writes

Running `main.py` writes a single 120-character one-line joke to `/output/entry.txt` (or to the path in `ENTRY_OUTPUT`). The output is deterministic: every run produces the exact same file.

## Run it

```sh
python3 main.py
```
